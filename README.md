# Jonathan Innovation Studio

Consumer Behavior & Insights course · final project studio website

- **Topic**: 01 · TALKLOOK Urban Escape community-store transition
- **Core concept**: Community Living Room — one café hosting solo relaxation, group conversation, and small meetings
- **Brand**: TALKLOOK ® (Ningbo · est. 2019)
- **Framework**: Recognize → Acquire → Perceive → Product → Retain (five-step consumer journey)
- **Assessment**: Eight-phase project rubric (Objective 13% · Consumer Research 16% · Insight 15% · Ideation 15% · Testing 15% · Scaling 11% · Ethics 8% · Report Standards 7%)

## Run locally

Open `index.html` directly in a browser. The photos under `assets/` are local enhancements; if missing, the page falls back to built-in CSS scenes without affecting readability.

## Structure

```
├── index.html        # Single-page site (self-contained styles and scripts)
├── assets/           # Local photos (hero / alone / gather / meeting)
└── README.md
```
