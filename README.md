# Jonathan Innovation Studio

消费者行为与洞察课程 · 期末项目工作室网站

- **课题**：01 · TALKLOOK Urban Escape 社区门店转型
- **核心概念**：社区客厅（Community Living Room）——一间咖啡店里同时容纳独处休憩、多人交流与小型会议
- **品牌**：TALKLOOK ®（宁波 · 始于 2019）
- **框架**：识客 → 获客 → 感知 → 产品 → 留存（消费者旅程五步）

## 本地运行

直接用浏览器打开 `index.html` 即可；`assets/` 目录下的实拍配图为本地增强，缺失时页面会自动使用内置 CSS 场景，不影响阅读。

## 目录结构

```
├── index.html        # 单页网站（自包含样式与脚本）
├── assets/           # 本地配图（hero / alone / gather / meeting）
└── README.md
```

## 交付物（课程）

1. 社区门店定位方案
2. 社区客群画像（画像 · 需求 · 痛点）
3. 产品 / 获客建议
4. 约 2,500 字消费者行为解码咨询报告
